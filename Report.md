# Задание 2.2. Кастомизация статического сайта (шаблонизация, сборка статики: HTML, CSS, JS)
**Выполнил студент группы P4207 Князев Илья.**

## Ход работы
1. Устанавливаем необходимые зависимости
2. Создаем шаблон `main.html` при помощи Jinja2
3. Отдельно создадим компоненты `header.html` и `footr.html` и вставим их в `main.html` при помощи `{% include "component" %}`
4. Добавим стили в `style.css`
5. Добавим немного динамики, добавив кнопку и навесим на нее несколько слушателей событий в файле `main.js`
6. Чтобы использовать шаблон добавим в файлы `.md`:
```markdown
---
template: main.html
---
```
7. Изменим `mkdocs.yml`, добавив несколько переменных, а также `theme` и `nav`
8. При сборке можем увидеть, что все работает корректно
9. Далее настраиваем развёртывание с помощью GitHub Actions. Все действия описаны в `deploy.yml`, внутри которого настроены шаги по настройке окружения, установкой зависимостей, генерацией статических файлов, валидацией HTML при помощи `vnu`, минификацией js и css (при помощи `clean-css-cli` и `terser` соответственно) и непосредственно публикацией на GitHub Pages.
